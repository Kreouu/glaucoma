# ConvNeXt512 EMA学习率对照

先冻结98.16材料，不改推理源码。现有单EMA43已用batch1复测，AUROC0.9884364、AP0.8151758、18.98ms，仍需全量独立重载与CSV校验，线上未知。

本轮只改固定学习率：原3e-5对照已完整保存；1e-5与6e-5各跑seed42、5轮。保持ImageNet初始化、512、batch16、w3、AdamW/wd0.01、水平翻转、FP16及EMA0.999。若最优seed42比原EMA42提高至少0.0005，补跑同一学习率seed43/44；否则结束筛选，最多四次训练。三种子平均配对AUROC增益至少0.0005且至少两种子正向，才进入batch1候选核验。AP报告但不作为硬门槛。

每次训练后独立重载普通及EMA权重，核对完整5849张/191阳性、数据顺序、源码/权重哈希和五轮指标。候选始终从公开原始权重训练；不在测试集拟合或选择。反复使用同一验证集的筛选结果可能乐观，不把验证提升等同线上提升。

脚本：`python scripts/run_convnext_ema_lr.py`；源/data/预训练哈希及筛选条件：`docs/evidence/convnext_512_ema_lr_v1/plan.json`；队列日志：`outputs/convnext_512_ema_lr_v1.queue.log`。按历史每轮约10.5分钟，筛选约1小时45分，补跑后总计约3.5小时，另加验证。

抽看官方训练集24张的视野：存在大小不一的圆形视野、暗图和遮挡，不足以定义安全裁剪规则。本轮不改裁剪、不增模型规模、不安装量化依赖。

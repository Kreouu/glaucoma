# 数据审计

在 WSL 项目根目录运行，`--data-root` 指向包含 `train.csv`、`valid.csv`、`train/`、`valid/` 的目录：

```bash
/home/ng/miniconda3/envs/glaucoma/bin/python scripts/audit_data.py \
  --data-root /实际数据路径/glaucoma_first \
  --output-dir outputs/data_audit \
  --workers 4
```

脚本只读训练集和验证集，不修改原始文件，不读取测试集。依赖 Pillow（已在比赛环境安装）。

检查 CSV 字段、标签、年龄、重复文件名、缺失图片、未列入 CSV 的文件、图片校验及完整解码；统计尺寸与宽高比，并分别计算文件 SHA-256 和解码后 RGB 像素 SHA-256，检查集合内与跨集合完全重复、重复图标签冲突。

若 CSV 与实际文件名仅大小写不同，脚本只在忽略大小写后存在唯一匹配时读取图片，并在摘要中统计数量、在清单中记录 `actual_filename`。原文件不重命名，训练读取器也需要采用明确的文件映射。

输出目录包含：

- `report.md`：摘要。
- `summary.json`：字段统计、尺寸统计、CSV 哈希及问题计数。
- `issues.csv`：需要检查的问题清单。
- `duplicates.json`：重复组及其成员，文件与像素两种方法分别记录。
- `image_manifest.jsonl`：每张图的尺寸、哈希和解码结果。

没有问题时返回码为 0；有待检查问题时为 1。`REVIEW_REQUIRED` 不代表必须删除数据，应根据具体问题决定处理方式。没有发现完全重复，也不能证明不存在近似重复或同患者泄漏。

详细输出含比赛文件名与数据统计，留在被 Git 忽略的 `outputs/`，不要公开上传。若重新运行同一输出目录，将覆盖上一次审计结果。

## 关键实验结论

以下结果只适用于已测试配方；单次失败不代表整个架构或方法无效。

| 方向 | 结果与决定 |
|---|---|
| B0类别权重与分辨率 | 权重3、较高分辨率有效，建立早期基线 |
| 架构对照 | 已测B3、SwinV2、InceptionNeXt、FasterViT等；当前选择ConvNeXt作为主力 |
| ConvNeXt分辨率 | 512取得线上提升；640未形成可靠收益，保留512 |
| EMA与学习率 | EMA及LR1e-4三种子方案形成线上最佳98.38 |
| 延长轮数 / 余弦 / EMA0.9995 | 已测配方未稳定超过保留方案；不据此断言余弦普遍无效 |
| 常规正则化 | 光照增强、BCE权重1/5、Mixup、Focal、排序正则、随机深度的已测设置无晋级收益 |
| 其他模型 / 特征 | EfficientNetV2-S、ConvNeXt-Small、DINOv2及训练特征近邻的已测配方未超过主力 |
| ImageNet22K初始化 | 单模型提升很小且种子不稳定；42作为互补成员提高本地组合指标 |
| 训练轻裁剪 | 单模型AUROC未提高，但作为互补成员改善本地组合；上线六模型仍只有98.37 |
| 固定中心裁剪TTA | 六模型初筛AUROC0.991468，仅+0.000081，未达门槛，停止该设置 |
| 年龄辅助融合 | 固定初筛收益不足，不进入正式推理 |

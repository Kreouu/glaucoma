# 图像基线实验记录

## 完整一轮基线

- 实验目录：`outputs/baseline_20261027_233625`（数据和训练产物不提交 Git）。
- 模型：EfficientNet-B0，ImageNet-1k 初始化；权重来源见 [核对说明](../licenses/efficientnet_b0/核对说明.md)。
- 划分：官方训练集 51,396 张，官方验证集 5,849 张（191 张阳性）；不使用测试集。
- 配置：256 输入、batch 16、workers 4、随机种子 42、普通 BCE、AdamW、学习率 1e-4、weight decay 0.01、AMP、1 轮；不使用年龄。
- 预处理：JPEG 缩小解码、RGB、保持宽高比缩放后黑色补边、固定 ImageNet 归一化；训练仅增加随机水平翻转。

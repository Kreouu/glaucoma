# 全图/局部方向可行性检查

2026-11-04。当前最高已核验候选AUROC0.992312；本记录不是实验结果。

原始依据：
- https://arxiv.org/html/2504.00431v1 ，方法3.1/3.4：全图、ROI、动态窗口三分支。其中ROI依赖外部预训练分割模型，当前不能直接复现整套配方；动态窗口从特征图选择区域可作为设计参考。
- https://pubmed.ncbi.nlm.nih.gov/34153436/ ：图像级监督的注意力定位具备可行性依据，但该研究使用立体图像对，与本任务输入不同。

下一步选择：先用已训练Tiny的训练集图像特征生成区域预览，检查是否集中于有效眼底且定位随成像变化稳定。只用训练图像作方案设计；不引入外部医学权重/标签，不将激活热点称为已定位视盘，不根据模型输出改标签。

若区域可靠，再比较全图分支与全图+局部分支；若区域不可靠，则不直接启动长训练。已失败的亮区裁剪及空间池化结果不等同于本方向，但说明必须先做定位验收。

部署约束：局部分支需计入全部权重及解码/区域选择/推理耗时。不得仅引用论文指标宣称本比赛有增益。

## 首轮48张训练预览

固定随机种子20261104，各24阳性/阴性，seed42模型；GradCAM针对阳性logit，最后空间特征层，模型参数冻结仅求输入/特征梯度。全部完成，预览位于 outputs/training_cam_v1/training_cam.jpg。人工目视：部分阳性激活在视盘附近，也有弥散响应；阴性可出现图像边界/黑背景激活。没有解剖定位标签，不能给出视盘定位准确率，更不能称可靠分割。当前不直接据此启动局部裁剪长训练，先需几何稳定性/有效眼底约束检查。

## 翻转稳定性检查

同一48张训练图像，RGB最大通道>0.08作为固定有效区域，正类logit GradCAM。阳性24张的有效区域激活质量比例中位数0.997224，反向映射水平翻转后top10%区域IoU中位数0.887539，掩膜内峰值位移/512中位数0。阴性24张对应0.676770、0.717673、0.105725。全部热图非零。数值是小样本描述性检查，不是解剖定位精度，也未证明验证收益。

决定：继续制作固定尺寸热点局部框预览，重点检查阴性稳定性和结构保留。定位算法必须不依赖真实标签；若训练局部分支，训练区域只能由训练图像/训练所得模型生成，推理同规则，不使用验证标签拟合位置。

## 固定局部框预览

同48图，所有标签统一使用154/256边长的窗口，最大化CAM均值且有效区域覆盖>=80%，无可用响应时回退最大覆盖率。人工查看全图/局部并排预览后：多数框包含视盘附近及周围区域，少数阴性偏移或视盘靠框边缘。不能称解剖定位已通过。决定仅作为辅助视图实验，必须保留全图；不能把局部替代全图。预览 outputs/training_cam_boxes_v1/training_cam.jpg，精确框及回退记录 crop_selection.json。

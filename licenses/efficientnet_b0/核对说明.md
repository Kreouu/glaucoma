# EfficientNet-B0 预训练权重核对

核对日期：2026-10-27。用途：本项目比赛图像分类基线；尚未用于完整数据训练。

## 结论及证据边界

已取得具体上游模型卡的 Apache-2.0 许可标记及 ImageNet-1k 数据声明，不是仅引用代码仓库许可证。结合 torchvision 官方的移植来源声明与本次张量核对，具备将该 torchvision 权重作为基线候选、随材料申报的公开依据。规则没有要求所有通用预训练模型都提前申请个别许可，当前不需要先向主办方申请特例。

这是公开资料核对结论，不是主办方已审核通过，也不是法律保证。timm 通用 README 仍提示 ImageNet 数据条款可能影响权重，torchvision 也要求使用者自行核对具体模型条款；这些说明完整保留，不能隐去，也不能将所有 ImageNet 权重一概宣布合规。最终核验以主办方书面规则为准。

## 对应关系实测

WSL 中使用 PyTorch 2.10.0 的 `torch.load(..., weights_only=True)` 分别加载两个原始文件，对每个张量计算 `(dtype, shape, SHA256(连续数组字节))`，比较其多重集合。

结果：两边各 360 个张量，张量指纹多重集合完全相同。该检查独立于参数键名，证明张量内容的一致性；不等于两个文件字节一致，也不单独证明所有层的计算图或参数位置一致。模型卡对应关系由该检查和官方移植声明共同支持。

同时通过当前 `build_model` 严格加载 torchvision 原始 state_dict、替换二分类头，在 RTX 5060 Ti 上以 AMP 对随机输入执行前向，输出为有限值、形状为 `(2, 1)`。结果见 `verification.json`。没有读取比赛测试集，也没有启动正式训练。

## 许可与再分发留档

具体上游模型的 Apache-2.0 标记见 `timm-model-card.md`。许可证全文见 `timm-LICENSE.txt`；torchvision 实现的 BSD-3-Clause 全文见 `torchvision-LICENSE.txt`。二者角色不同，不以代码许可代替模型卡声明。

按 Apache-2.0 第 4 节准备再分发材料：随包提供许可证副本；保留适用版权、署名和归属通知；若原分发含 NOTICE，则保留适用 NOTICE；修改后的文件应显著说明已修改。最终材料需注明训练后权重由比赛官方训练集微调、分类头由 1000 类改为单 logit。不要将微调文件冒充原始权重，不以作者或机构名义背书。

`manifest.json` 记录每份原始资料的 URL、下载时间、大小及 SHA-256。模型卡使用固定 revision，torchvision 使用 v0.25.0 标签。timm 通用 README/LICENSE 使用下载时的 main 快照，因此以所存文件哈希固定本次证据。当前未在模型仓库文件列表发现独立 NOTICE；最终打包时若新增来源，应重新检查通知文件。

本地赛事规则对照：`docs/参赛规则.pdf` 第 1 页第 1 条及第 5—6 页附录 A；`docs/补充规则.pdf` 第 1—2 页第二节。材料要求包括模型名、权重公网直链、许可证全文、上游数据说明、原始权重 SHA-256。当前不是最终提交包，队伍声明表和最终推理精度仍待正式模型确定后填写。
